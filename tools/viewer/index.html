Robot Dataset Viewer — Help

Left panel — Robot mode buttons

State
URDF robot driven from observation.state — what the robot was at each frame.
Action
URDF robot driven from action — what the policy commanded at each frame. Useful to spot tracking errors when state and action diverge.

Right panel — EE mode buttons

FK Val
Forward-kinematics validation. Blue/red = observation.ee_left/right (dataset-recorded EE). Cyan/orange = EE re-computed from URDF after applying state joints. Yellow line = FK error — invisible when correct.
Obs/Act
Observation EE vs Action EE. Blue/red = observation.ee_left/right. Cyan/orange = action.ee_left/right. Yellow line = tracking gap. Requires joint_to_ee.py --include-action.
EE Δ
Sequential delta of the action EE. Blue/red = observation EE position. Green arrows = direction of action.ee_*.delta (EE[t] − EE[t−1]). Arrow length is proportional to delta magnitude (scaled ×8). Footer shows mm gap.
EE Rel
Relative action EE (action EE relative to current observation EE). Blue/red = observation EE position. Purple arrows = direction of action.ee_*.relative (action EE − obs EE). Requires joint_to_ee.py --include-action.

Coloured elements

Blue — left arm observation EE
observation.ee_left — absolute EE position recorded in the dataset.

observation.ee_right — absolute EE position recorded in the dataset.

action.ee_*.delta — sequential EE delta direction and magnitude.

Grey spheres
Arm mount reference points on the mobile base (fixed positions).
Axis arrows
End-effector orientation frame from observation.ee_*.

Joint calibration (gear button ⚙)

Per-arm calibration: urdf = sign × value + offset per joint, per side. Use this when one arm's encoders are biased relative to URDF zero.

Fast workflow: pause on a frame where you know the arm is at its physical home pose, then click "Snap current → zero" for that arm. The offsets are auto-set so the URDF renders that frame as home, and motion is preserved relative to it.

Sign toggle flips axis convention, offset slider shifts the zero point. Reset per-arm restores identity. Settings persist in localStorage.
